Overview

Hack The Box provides deliberately vulnerable machines to compromise in a legal, isolated environment. I have owned more than 20 machines so far.

Alongside the machines, I'm working through the HTB Academy Penetration Tester path, keeping structured notes on each module. Modules covered so far include footprinting and service enumeration, web information gathering, vulnerability assessment and file transfer techniques.

Why

To build practical offensive skills against realistic targets, and to understand attacks well enough to recognise and detect them from the defender's side.

Approach

Each machine follows a structured penetration testing process: enumeration, initial access, then privilege escalation. For machines I write up, I also cover how a defender could detect and mitigate each stage.
